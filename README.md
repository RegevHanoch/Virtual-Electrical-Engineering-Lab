# Virtual Electrical Engineering Lab

A C-based virtual electrical engineering laboratory developed using LabWindows/CVI.

The project combines signal generation, measurement, signal processing, filtering, frequency analysis, and external data acquisition in a single interactive environment.

## Features

- Dual-channel signal generation and oscilloscope measurements
- FFT-based spectrum analysis and harmonic detection
- Butterworth LPF, HPF, and BPF filtering
- Bode magnitude and phase analysis
- Real-time analog voltage acquisition using Arduino UNO
- ADC sampling and Serial communication
- Multithreaded signal generation
- CSV and Microsoft Excel data export

## Electrical Engineering Concepts

The project applies concepts from electrical engineering studies, including:

- Signal processing
- Sampling theory and Nyquist criterion
- FFT and frequency-domain analysis
- Digital filtering
- Transfer functions and frequency response
- RMS, Vpp, frequency, and period measurements

## Technologies

`C` `LabWindows/CVI` `Arduino UNO` `FFT` `Digital Signal Processing` `Serial Communication` `Multithreading` `ActiveX`
